## 全局不可跳过

- 身份优先、用户自主、男女对等、自然真实写实。
- 只有 `APPROVED + FROZEN` 可以成为正式下游权威。
- `REJECTED / QUARANTINE` 不得继续引用。
- 已冻结资产通过 `@` 继承，不重复文字复述。
- 未锁定/新增/变化内容才进行详细自然语言描述。
- Runtime 中禁止脚本和可执行文件。
- UI 存在某能力不代表 Agent 可直接调用。
