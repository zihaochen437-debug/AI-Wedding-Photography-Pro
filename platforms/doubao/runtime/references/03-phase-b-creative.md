# Phase B｜婚纱创意生产

仅当 AB01/AB02/AB03 均 `APPROVED + FROZEN` 后进入。

## 1. 输出类型 Gate

A. 只制作婚纱照片  
B. 只制作婚纱视频  
C. 照片 + 视频

## 2. TARGET_PHOTO_COUNT_GATE

有照片时先问最终独立保留数量：6 / 9 / 12 / 18 / 24 / 36 / 48+ / 自定义 / AI推荐。不是候选数或生成次数。

软规划：6–9 以 1 个主要视觉方向为主；12–18 约 1–2 个方向/Look/Scene；24–36 可规划 2–3 个主要方向与多 Scene/Sequence；48+ 适合完整多套系。它是软基线，不是硬公式。

## 3. BROAD_CHOICE_PRESENTATION_POLICY

用户“都有什么/多看看/没想好”进入 `FULL_CATALOG_MODE`；已有偏好进入 `RECOMMENDATION_MODE`，建议 6–10 个真正有跨度的方向，并始终提供更多同类、完整分类、自定义、上传参考。

能力范围包括但不限于：经典、韩式清透、法式轻奢、现代极简、高定影棚、Editorial、电影纪实、电影情绪、复古胶片、草坪、森林、海边、山野、花海、城市街拍、城市夜景、欧式建筑、法式室内、新中式、秀禾、龙凤褂、汉服、明制、宋制、民国、东方高定、旅行、创意实验。

## 4. 多选与分支

Suite / Style / Look / Scene / 产品比例可多选，但默认建立独立 `SUITE-0N` 分支，不把所有方向塞进一个 Prompt。用户明确要求“融合”时才建立复合风格。

## 5. Look 与 Scene 联动

`SUITE → STYLE → LOOK → SCENE` 联动推荐。AB04/05 分别审核冻结后再建立 AB06。道具可以作为独立资产/Shot 参考。

## 6. 交互

Phase B 支持多选。优先使用当前平台原生控件；否则使用结构化选项/A-B-C 菜单；始终保留“其他/自定义”。
