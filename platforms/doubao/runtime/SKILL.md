# Ai婚纱摄影

**Ai婚纱摄影**是一套面向真人情侣的商业级 AI 婚纱摄影与动态影像生产 Skill。它不是简单换婚纱、换背景或随机出图，而是先建立并由用户确认人物身份、真实身高与身体比例，再完成男女完整妆造、场景、道具、摄影导演、商业分镜、正式婚纱照片与婚纱视频。

## 主要能力

- **人物身份与真实比例**：基于真人参考建立 AB01 新娘、AB02 新郎、AB03 双人标准资产，避免同脸、串脸、身份互换和比例漂移。
- **用户自主精修**：R0–R4 在人物标准资产建立前确定；个人标志、体型、身体特征和辅助器具均以用户选择为准。
- **男女同等级妆造**：AB04 新娘 Look 与 AB05 新郎 Look 同等完整，妆发、礼服、鞋履、配饰、材质和 QC 不偏科。
- **Scene 与商业摄影导演**：AB06 建立同一世界的场景母版；按 Scene → Look → Sequence → Shot 组织 Hero / Support / Detail / Safety Shot。
- **专业镜头语言**：规划景别、距离、机位、方位、俯仰、镜头与曝光意图，并转译成真实可见的透视、景深、空间压缩、动态和光影。
- **照片与视频一体化**：照片与视频共享 AB01–AB06；VB01 负责视频分镜、时间轴、动作、运镜、声音和转场。
- **受控修订**：修改什么只开放什么；已批准的脸、妆造、Scene、构图、机位和其他区域保持冻结。
- **工程化工具链**：在豆包运行环境真实允许时，可使用脚本进行资产台账、非生成式资产板排版、尺寸计算、批次规划、时间轴验证和媒体处理。

## 核心原则

1. 人物身份优先于风格和美化。
2. 新娘与新郎是两个独立身份；群演不得继承主角肖像。
3. 男女主角制作等级对等。
4. 标准人物、Look、服装和道具资产统一使用 `#FFFFFF` 纯白无缝背景与自然中性柔和面光；AB06 Scene Base 使用真实场景与自然中性基准光。
5. 已 `APPROVED + FROZEN` 的资产通过 `@资产` 直接继承，不重复用文字重新解释；Prompt 只详细描述尚未锁定、本轮新增或变化的内容。
6. 正式 Shot 第一次生成就按商业成片质量执行；用户批准后，不为了“最终版”随机重生另一张图。
7. 所有运行能力必须诚实标记；界面有按钮、包内有脚本或厂商存在模型，都不等于当前豆包会话已可直接调用。

## 使用流程

**参考指南 → 上传方式 → 资料补充确认 → S/A/B/C/D 评级 → 人物资料与个人特征 → R0–R4 → AB01/AB02/AB03 审核冻结 → 输出类型 → 照片数量或视频需求 → 套系/风格 → AB04/AB05 → AB06 → 摄影/视频导演 → 正式生成 → QC/用户审核 → 必要 Scoped Revision → Approved Baseline → 产品派生/按需超分 → 最终交付**
