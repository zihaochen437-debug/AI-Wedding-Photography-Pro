# AI Wedding Photography Pro v1.9.0

[English](#english) | [简体中文](#简体中文)

## English

This is the first public GitHub release of **AI Wedding Photography Pro** as a platform-agnostic, identity-preserving framework for commercial AI wedding photography and wedding cinematic production.

### Highlights

- Introduces **Universal Core v1.9.0** as the platform-independent production standard.
- Includes **Xiaoyunque v1.9.0** as a compact declarative Skill runtime with no executable scripts in the package.
- Includes **Doubao v1.9.0** with manifests, references, registries, schemas, templates, and deterministic Python tooling where the runtime actually supports it.
- Establishes AB01–AB06 identity/look/scene assets and VB01 video storyboard/timeline assets.
- Uses `APPROVED_ASSET_AUTHORITY + DELTA` for photo, video, revision, and regeneration prompts.
- Includes R0–R4 user-controlled refinement, Scene → Look → Sequence → Shot planning, Camera Geometry, Scoped Revision, photo-to-video, segment-level video revision, and QC.
- Adds repository-level regression validation with GitHub Actions.
- Licensed under **Apache License 2.0**.

### Architecture

```text
Source Archive / Research
        ↓
Active Canon
        ↓
Universal Core
        ↓
Platform Adapter
        ↓
Platform Runtime Package
```

Platform adapters may change execution mechanics, but must not silently weaken identity fidelity, approval gates, user autonomy, asset authority, revision scope, or QC standards.

### Release assets

This release publishes source packages for:

- Universal Core v1.9.0
- Xiaoyunque runtime v1.9.0
- Doubao runtime v1.9.0

### Privacy

No real client photos, private reference assets, API keys/tokens, sensitive body/health records, or private project state are included in the public release.

## 简体中文

这是 **AI Wedding Photography Pro / Ai 婚纱摄影 Pro** 首个正式 GitHub 公共版本。项目定位为一套平台无关、以真人身份高保真为核心的商业级 AI 婚纱摄影与婚纱动态影像生产框架。

### 主要更新

- 正式建立平台无关的 **Universal Core v1.9.0**。
- 发布 **小云雀 v1.9.0** Compact Runtime：声明式 Skill 结构，正式包不包含脚本或可执行文件。
- 发布 **豆包 v1.9.0** Runtime：包含 manifest、references、registries、schemas、templates，以及在运行环境真实支持时使用的确定性 Python 工具。
- 正式统一 AB01–AB06 人物 / Look / Scene 资产与 VB01 视频分镜 / 时间轴资产。
- 照片、视频、局部修改和重生成统一采用 `APPROVED_ASSET_AUTHORITY + DELTA`。
- 纳入 R0–R4 用户自主精修、Scene → Look → Sequence → Shot、Camera Geometry、Scoped Revision、Photo-to-Video、视频片段级修订与 QC。
- 增加 GitHub Actions 自动回归验证。
- 项目正式采用 **Apache License 2.0**。

### 架构

```text
Source Archive / Research
        ↓
Active Canon
        ↓
Universal Core
        ↓
Platform Adapter
        ↓
Platform Runtime Package
```

平台 Adapter 可以改变“怎么执行”，但不得静默削弱人物身份、用户审批、用户自主权、Asset Authority、Scoped Revision 或 QC 标准。
