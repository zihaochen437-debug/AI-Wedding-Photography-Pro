# Prompt 示例

## 已有权威资产的照片 Shot

严格参照 @AB04 保持新娘当前完整人物与妆造，严格参照 @AB05 保持新郎当前完整人物与妆造，严格参照 @AB06 保持当前 Scene；严格执行 @BLOCKING-08 与 @CAMERA-12 已确认的站位、动作、景别和摄影机关系。

本轮只增加黄昏自然侧逆光：主光从画面右后方进入，头纱边缘有轻微透光，人物正面保持自然中性补光，肤色准确，婚纱与深色礼服均保留材质层次。真实商业婚纱摄影质感。

## 没有 Motion 资产的视频片段

严格保持 @AB04、@AB05 的当前人物与妆造以及 @AB06 的 Scene。0–3 秒两人保持并肩全身构图，新郎先转头看新娘；3–7 秒新娘回应视线并轻微微笑，两人向前同步走一步；摄影机从正前方约 6 米位置缓慢推进并向右做小幅弧形移动，速度均匀，最终形成七分身构图。右后方轻风使头纱向左后方自然摆动，动作克制，脚始终稳定接地。

## Scoped Revision

严格保持当前已批准画面的人物身份、妆造、站位、Scene、景别、机位、构图、灯光和色彩，只修复新娘右手及必要的最小手腕连接区域，使手掌、五指、手腕与花束握持关系自然完整。其他内容不得变化。
