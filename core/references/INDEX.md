## 路由原则

1. 当前任务只读取真正需要的 references。
2. Active Canon 决定什么规则有效；长篇历史研究只能提供证据和设计来源。
3. 平台 Adapter 负责“如何执行”，不能削弱人物身份、审批门、用户自主、资产权威、Scoped Revision、声音边界和 QC。

5. 外部 GitHub Skill 与专业资料必须先经过来源/许可/冲突审计，再转化成本项目自己的 Canon。
