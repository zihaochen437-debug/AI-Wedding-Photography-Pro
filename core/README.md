# Universal Core

The `core/` directory contains the platform-agnostic production semantics of AI Wedding Photography Pro.

Platform adapters must preserve this layer and translate it into platform-specific execution without silently weakening requirements.

## Core domains

- identity and reference governance;
- R0–R4 refinement and personal-feature autonomy;
- AB01–AB06 asset semantics;
- look, wardrobe, prop, and scene systems;
- photography directing and commercial shot planning;
- photo production;
- video production and VB01;
- authoritative-assets + delta prompt compilation;
- scoped revision and regeneration;
- QC, asset state, dependency, invalidation, and delivery.

## Governance

Active Core rules are derived from project research and Active Canon. Historical or superseded rules should not be reintroduced through platform adapters.

Current adapter priorities: Xiaoyunque and Doubao.
